VERTO SKILLX — STUDENT SKILL EXCHANGE DEMO

HOW TO RUN
1. Extract verto_skillx.zip.
2. Open the folder in VS Code.
3. Install/use Live Server, then open index.html with Live Server.
4. Register two or more test students in the SAME browser and browser profile.
5. After registration you return to the Community home page. Use search and filters to find students, open View profile, and send connection requests.
6. Log in as the other test student to accept requests from My profile.

MAIN FEATURES
- Community directory on the home page with student cards.
- Search by student name or skill, plus skill and learner/teacher filters.
- Public student profiles with skills, about section and available sessions.
- Private My profile link in the header.
- Connection requests and accept flow.
- Separate skill, schedule, registration, login, about, FAQ and support pages.

IMPORTANT LIMITATION
This is a frontend college-assignment prototype. Data is stored in browser localStorage. It is shared only between pages in the same browser profile on the same device; different students using different devices/browsers will NOT see each other's registrations or requests. To make it a real online campus platform, connect a backend such as Firebase or Supabase for authentication, database, profile photos and real-time messaging. Do not enter real passwords or sensitive personal information.
